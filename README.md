J. Jams Hair Salon is a hair salon in Orange County that offers professional hair styling services for all ages and genders. For addition services, customers may select from the various premium treatments offered. A program to facilitate the transactions which take place via the salon website with customers who wish to book an appointment for their desired service is necessary so that all guests’ wishes are considered. ### Program Goal
The goal of our project is to provide a program that can perform the functions needed to accommodate various appointments and treatments at a salon. The program requires user input to for the purpose of scheduling an appointment on a particular date and time. The program will allow authorized authorize customers to be able to view and choose from a menu of services provided by the salon. Inputs include the customer’s personal contact information, financial information, and their appointment details. Finally, the program will generate details of customer appointments in a receipt format to summarize the subtotal owed. An itemized log file of all scheduled appointments with customers will be generated.

### Program Design and Function
Our entire program is written within the GUI form. Our code relies heavily on users inputting information in labels or clicking on list items and then clicking some type of button to cause another event to happen. 
To begin the program, we created a text document named “user.txt” with a list of registered authenticated users including their username and password. Users are asked to login with their user information in labels before given access to the website and allowed to make an appointment for desired services. Our program uses a FileStream and StreamReader to open and read all the rows from the file to determine whether the user is an authenticated customer. To do so, we created a 2D array which stores the user details (username and password) and used the “Split" method to store each username and password in an index. From here, the program uses a “While” Loop that continues as long as a line is not null to split the attributes and compare it to the user inputs. If the entered username and password match the records from the text document, then the user is granted access to the menu of services offered displayed in the GUI form. If not an authenticated customer, then the user does not have the right to reserve an appointment with our salon. The program will display an error message stating that “Username and password is incorrect.” If the user is seeing this message they either entered in their log in information wrong or they are not an authenticated user.
From here, authenticated customers are given access to the GUI form to review the list boxes of available stylists and services offered. All the stylists, haircuts, add ons, times, and cost values are stored in a text document. Our program then reads from the text document using FileStream and StreamReader by looping through the values through a 2-D array and their indexes to display them on the listboxes. The loop stops when it reaches the end of the array. To find the stopping point, we used the “GetLength” method within our conditions for each of our “For” loops. On the GUI form, the user can then click on each label of their desired services. If further descriptions of treatments and add-ons are needed, we have placed a button for users to click, which pops out detailed descriptions of each treatment and add-on offered at the salon. After clicking on the labels of the desired service, a menu list of the selected services along with their respective prices and total time required for their appointment is displayed. Since all of our times have been stored as minutes, we used division and modulo to add up the total minutes needed for the appointment and display them in hours and minutes. The estimated total cost of the services chosen and the tax amount to be charged is also displayed. Prices are read from another text document, which contains our services and their respective prices, using a streamreader. Users are asked to confirm the selected stylist and services chosen by clicking a “Confirm” button. 
After confirming, the user is given access to select a date and time. For this portion of the code, we used a ComboBox that displays the available days and specific times for which the user can pick. Once appointment details are selected, the user must click a button to confirm their date and time and be directed to enter their billing information.The billing information side of the form is only made visible after selecting a time and date for the appointment.  All personal information (Name, Address, Credit Card Number, Expiration Date, and CVC code) is inputted into labels. After that, the user must enter a valid credit card in order to reserve the appointment. To check this, our code uses an “IF Statement” to determine whether the entered credit card number is 15 or 16 digits. If the entered credit card information is valid, then their payment is processed and the hair salon appointment is officially confirmed. If the entered credit card number is not 15 or 16 digits long, then the program returns an error message stating that the card is invalid. The user must re-enter a valid credit card number. Once that is done, then the appointment is officially reserved.
After a hair salon appointment is confirmed, our code outputs a receipt for the customer’s transaction which includes the selected services and respective prices, along with the tax and the total cost. At the top of the receipt, the customer’s name, appointment date, stylist chosen, and the last four digits of the credit card used to pay for their appointment is also displayed. To display only the last four digits of the entered credit card number, the program uses the SubString method. From there, we used string concatenation to attach the “****” to the last four digits.  To make the format of our receipt visually appealing, our code uses the “ToString” method and left aligns all the values using proper spacing and place holders. To output the receipt, we used a FileStream and StreamWriter to transfer a particular customer transaction and the customer's inputs to the receipt text file. Each receipt is unique to a customer’s appointment details. At the end of our code, our program closes the receipt file. In addition to receipts, our code also outputs a master log file for the salon to keep records of all the appointments made through the program and their details regarding who they were made by. Similarly, it also uses a FileStream and StreamWriter to transfer all the customer transactions made and write their inputs to the master file text document. The log file text document includes rows of each transaction detailing the customer’s name,  date/time reserved, address, total cost, and the chosen stylist’s name. If running the program for the first time, then the master log file is initialized and every new transaction made is added until the program is ended. If the program is not running for the first time, then our code first verifies whether the master file already exists. If it exists, then every new transaction made is added to the file until the program is ended.
